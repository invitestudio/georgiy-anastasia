## Как обновить сайт

1. На странице репозитория: **Add file → Upload files**
2. Перетащить **содержимое** этой папки (не саму папку!)
3. **Commit changes**
4. Подождать 1–2 минуты

После обновления открывать сайт в режиме инкогнито или обновлять с зажатым **Ctrl** —
браузер держит старую версию в кэше.

## Анкета гостей

Ответы падают в Google Таблицу через скрипт Apps Script.
Адрес скрипта вшит в `index.html` (строка с `SHEET_ENDPOINT`).

**Главное правило:** после любой правки кода скрипта его нужно **заново развернуть**
(Развернуть → Управление развёртываниями → карандаш → Версия: Новая версия → Развернуть).
Иначе гости продолжают попадать на старую версию.

Подробности — в `ИНСТРУКЦИЯ-google-таблица.md`.
